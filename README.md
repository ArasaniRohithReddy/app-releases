[@ArasaniRohithReddy](https://github.com/ArasaniRohithReddy). Source code lives in private repos;
this repo hosts the **releases**, the **docs**, and the **issues**.

## Download

The easiest way is the **[website](https://arasanirohithreddy.github.io/app-releases/#download)**, which
always links the latest build. Or go straight to **[Releases](https://github.com/ArasaniRohithReddy/app-releases/releases)**
and pick the asset for the app and format you want. Releases are tagged `‹app›-v‹x.y.z›`
(e.g. `threat-model-reviewer-v1.0.0`). Every Windows build is **self-contained** — no .NET
install required.

## Report an issue / request a feature

Open one here — it'll ask which app it's about:
**[New issue ›](https://github.com/ArasaniRohithReddy/app-releases/issues/new/choose)**.

For **security vulnerabilities**, please use
[private reporting](https://github.com/ArasaniRohithReddy/app-releases/security/advisories/new)
instead of a public issue.
