One tool for the whole threat-model lifecycle

Deterministic analysis you can trust, with optional Copilot help that stays advisory.

Review

Open a .tm7 and get a stamped NOT READY / READY WITH NOTES verdict, a 0–100 score, and a prioritized findings list mapped to OWASP, MITRE, CWE and Microsoft Learn.

Fix

Apply built-in or Copilot-drafted fixes — added threats, triage, justifications, out-of-scope reasons — with round-trip write-back to a valid .tm7 that reopens in the Threat Modeling Tool.

Analyze

Go deeper on any finding — DREAD scoring, attack trees, mitigation plans and verification tests — then export to HTML, PDF, SARIF or GitHub / Azure DevOps / Jira work items.

Beta

Create is coming. Building a new model from a guided wizard — and having Copilot draft a data-flow diagram from a description, an architecture image or an OpenAPI spec — is in beta and rolling out in a future release. Today's build focuses on reviewing, fixing and analyzing existing .tm7 models.

Built to match a real SDL bar

Around 70 deterministic checks run entirely on your machine — the same issues a reviewer would flag, surfaced before you submit.

✓ STRIDE-per-element coverage

Every element and interaction checked for the STRIDE categories it should address, with a threats-by-interaction breakdown.

✓ AI & agentic surface

Dedicated checks for the OWASP LLM Top 10 (2025), OWASP Agentic threats and MITRE ATLAS on AI/LLM components.

✓ Triage & mitigation quality

Flags untriaged threats, “Not Applicable / Mitigated” without justification, and open high-priority work.

✓ Structure & hygiene

Completeness, identity & boundaries, data protection, network, logging/detection, deprecated crypto, supply chain and mismodeled stencils.

✓ Coverage scorecards

STRIDE matrix and a Framework coverage view (OWASP Top 10 + STRIDE) so gaps are obvious at a glance.

✓ Exports for every workflow

HTML, PDF, Markdown, CSV, JSON and SARIF, plus ready-to-file work items for GitHub, Azure DevOps and Jira.

✓ Copilot enrichments

Explain findings, deep DREAD/attack-tree analysis, draft fixes, whole-model critique and gap analysis — each advisory, never changing the verdict.

✓ Also reads Threat Dragon

Parses OWASP Threat Dragon .json models too, so mixed toolchains work in one place.

The score is yours to trust

The parts that decide readiness are fully deterministic and run locally. Copilot only assists.

Deterministic verdict

The NOT READY / READY-WITH-NOTES verdict, the 0–100 score and the findings come from a fixed rubric engine — never from AI. Copilot only explains findings and drafts fixes you choose to apply, so the same model always scores the same way.

Private by design

The deterministic review runs entirely on your machine. Copilot features send only minimal, redacted context — finding text and a data-flow summary — to your own Copilot seat, never the raw .tm7.

No telemetry

No analytics, no usage tracking, no vendor endpoint. The only request the app makes on its own is an anonymous release check — and that can be switched off, after which it works fully offline.

Built for enterprise rollout

Everything a security review and a deployment team need, documented up front.

✓ Security & privacy review

Every network destination, on-disk storage path and redaction rule is enumerated — plus how to verify the claims yourself with a proxy or offline run.

✓ Silent, managed installation

MSI with per-machine or per-user scope, documented UpgradeCode and silent switches for Intune, SCCM and Group Policy.

✓ Air-gapped & offline

Update checks can be disabled fleet-wide, after which the app makes no outbound request. The full review keeps working with no network at all.

✓ Keep inference in your tenant

Use GitHub Copilot, or point the provider at Azure OpenAI or a self-hosted OpenAI-compatible endpoint. Credentials are DPAPI-encrypted locally.

✓ CI/CD gating

The CLI runs the same deterministic engine headlessly and exits 2 when a model is not ready, so a pipeline can block on threat-model readiness. SARIF uploads to code scanning.

✓ Signed & auditable

Every artifact is Authenticode-signed and verifiable with Get-AuthenticodeSignature. Licenses for every bundled component are published.
