Before you download

Requirements and policies vary by app and release. Start with the product's own guides and package details.

Signing & integrity

Check the app's installation and security guides for signing status, expected publisher and available checksums. Do not assume every package is signed.

Platform & runtime

Use the app's install guide to confirm supported operating systems, architecture and runtime requirements for the release you choose.

Install & update

Package formats, administrator requirements and update behavior are app-specific. Find the right product guide before deploying.

Support & security

Use synthetic or redacted files, screenshots and logs in support reports—never credentials or private business data. Report vulnerabilities privately.

Privacy & data

Read the app's data-handling guide for local storage, network features and optional providers before using private inputs. Local processing does not mean every feature is offline.

License & notices

The hub's MIT license is not a summary of every download. Check the app's own license and bundled-component notices.
